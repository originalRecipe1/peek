Identity through composition

A compact wordmark, consistent corner geometry, stronger type hierarchy, and purposeful spacing can distinguish the app under any personalized Material palette.

This is a visual study of the existing home controls. The phone illustration is static; the palette, monochrome, and name controls are interactive.

For Android, use Material color roles throughout and preserve system-derived light/dark palettes. Develop the selected icon into an adaptive vector and a separate monochrome mask, then check launcher crops and small sizes.

Initial exact-name web searches and GitHub repository-name queries found no app collisions for these candidates. Store-domain searches also returned no results. This is preliminary discovery evidence, not a guarantee of exclusive use. This board records the initial exploration; Unfurlit was subsequently selected. See unfurlit.md for the implemented identity.
